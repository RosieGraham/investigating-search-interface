Privacy notice: Investigating Search Interface, SEASON 2026 workshop release

This notice covers the SEASON 2026 workshop release of the Investigating Search Interface browser extension and the server it connects to. Other releases of this extension are covered by their own notices.

What this extension does

The Investigating Search Interface is a research project of Dr Rosie Graham, University of Birmingham. It displays a short, expert-authored reflection prompt alongside your search results. It does not hide, reorder, alter or interfere with any search result.

Before it does anything

The extension does nothing until you have read a notice inside the browser and chosen to continue. If you decline, no search you make is sent anywhere. You can turn the extension off at any time from its toolbar icon or from your browser's extension settings.

What is sent, and what happens to it

When you make a search while the extension is active and enabled, the text of that search is sent to the project's server so that a relevant prompt can be selected. If you have chosen to exclude particular topics, that preference is sent alongside it.

The search text is used to select a prompt and is then discarded. This release does not keep it, does not attach any identifier to it, and does not record that a search took place or that a prompt was shown. Excluded-topic preferences are stored only in your own browser and are never kept on the server.

What this release does not do

It does not create a research record of your use. It does not assign your installation an identifier. It does not record which prompts you were shown, which you clicked, or which you dismissed. It does not collect written responses. It does not read the contents of search results, or anything on any other page or tab. It does not use analytics, advertising or tracking services of any kind, and it loads no third-party scripts or fonts.

Infrastructure

The server is hosted by Render in the European Union. As with any website you connect to, Render's own systems may record technical connection information, including IP addresses, under Render's policies rather than ours. We do not use that information for research and do not combine it with anything else.

Chrome Web Store Limited Use

The Investigating Search Interface's use and transfer of information complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Search text is used only to select the reflection prompt provided by the extension's single purpose. It is transmitted to the project's server hosted by Render only as necessary to provide that function, is not used for advertising, and is not made available for human reading except where required by law or necessary for security.

How the project uses what it learns

Because this release keeps no record of individual use, there is no personal data from it to analyse, publish or share. Findings from the workshop itself come from what participants tell us in the room, which is covered separately by the consent statement given at the session.

Your choices

You can decline the notice, turn the extension off, exclude topics you do not want prompts about, or remove the extension entirely. Because nothing is retained and nothing is identified, there is no stored record associated with you to access or delete.
