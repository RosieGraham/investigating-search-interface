Investigating Search Interface

A research project of Dr Rosie Graham, University of Birmingham.

This browser extension displays a short, expert-authored reflection prompt alongside your search results. It never hides, reorders or changes a search result.

The project asks what happens when a search engine is accompanied by a question rather than only by answers. An alpha release of the interface is featured in a hands-on workshop at SEASON 2026 in Hamburg in September 2026.

Using the extension

When you make a search while the extension is active and enabled, the text of that search is sent to this server so a relevant prompt can be selected, and is then discarded. This release keeps no record of your searches and gives your installation no identifier. You are asked to read a notice and agree before anything is sent, and you can decline or switch the extension off at any time.
